## 3. Description du service

SailPilot est une application d’assistance à la navigation de plaisance permettant notamment :

- la tenue d’un journal de bord ;
- l’enregistrement d’événements de navigation ;
- l’utilisation de données GPS et, le cas échéant, de données issues d’une passerelle NMEA/AIS compatible ;
- la consultation d’informations météo marines ;
- la génération d’exports PDF ;
- l’affichage de recommandations de configuration de voile et de notifications locales.
