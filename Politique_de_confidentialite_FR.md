## 2. À quoi sert l’application ?

SailPilot est une application mobile d’assistance à la navigation de plaisance.  
Elle permet notamment de :

- créer et gérer un journal de bord local ;
- enregistrer des événements de navigation ;
- utiliser la position, le cap, la vitesse et des données NMEA/AIS si disponibles ;
- associer des photos et preuves à une navigation ;
- générer des exports PDF ;
- afficher des recommandations de voile et des notifications associées ;
- consulter des informations météo marines ;
- protéger l’accès local à l’application par biométrie.

## 3. Quelles données peuvent être traitées ?

Selon les permissions que vous accordez et les fonctions que vous utilisez, SailPilot peut traiter les catégories de données suivantes :

### Données fournies par l’utilisateur
- nom du skipper, nom du bateau, informations de configuration du bateau ;
- contenus saisis dans le journal de bord ;
- remarques, incidents, observations et autres notes libres ;
- photos ajoutées au journal de bord.

### Données de navigation et de contexte
- position GPS précise ;
- cap, vitesse, horodatages, trajet, points de route ;
- mode de navigation (voile / moteur) ;
- données issues d’instruments du bord lorsqu’une passerelle compatible est connectée localement.

### Données techniques et préférences
- préférences locales de l’application ;
- état des notifications ;
- paramètres de connexion réseau locale à une passerelle ;
- état local de session et de reprise d’une navigation ;
- identifiant de profil local et éléments de sécurité locale.

## 4. D’où viennent ces données ?

Les données proviennent :
- directement de vous lorsque vous les saisissez ;
- du GPS et des capteurs du terminal ;
- du réseau local du bord lorsque vous connectez une passerelle compatible ;
- de services tiers utiles au fonctionnement de certaines fonctions, notamment pour la météo et certains services cartographiques.

## 5. Pourquoi ces données sont-elles utilisées ?

Les finalités principales sont les suivantes :

- fournir les fonctions de journal de bord, de navigation et d’assistance ;
- afficher la carte, la position, les événements et les exports ;
- générer des recommandations de voile ;
- envoyer des notifications locales utiles à la navigation ;
- récupérer des informations météo marines ;
- améliorer la fiabilité, la sécurité locale et l’intégrité des journaux ;
- répondre aux demandes de support.

## 6. Quelles sont les bases juridiques ?

Les traitements reposent principalement sur :

- **l’exécution du contrat** ou des mesures précontractuelles : utilisation de l’application et fourniture des fonctions demandées ;
- **votre consentement** lorsque le système iOS demande une autorisation, notamment pour la localisation, les photos, la caméra, les notifications ou la biométrie selon les cas ;
- **l’intérêt légitime** de l’éditeur pour la sécurité locale, l’intégrité des journaux, la prévention des abus et la gestion du support ;
- **les obligations légales** applicables, lorsque nécessaire.

## 7. Les données quittent-elles l’appareil ?

Une grande partie des données de bord est conçue pour rester **stockée localement sur l’appareil**.

Toutefois, certaines fonctions peuvent entraîner une transmission à des tiers techniques, par exemple :

- **services météo** pour récupérer des prévisions marines à partir d’une zone ou de coordonnées ;
- **services Apple liés à la cartographie / géocodage** pour certains affichages, cartes, instantanés ou noms de lieux ;
- **messagerie électronique** si vous contactez le support ;
- **App Store / Apple** pour la gestion des achats, abonnements, paiements, remboursements et éléments liés au compte Apple.

À la date du présent document, le build audité ne comporte pas de SDK publicitaire ni d’outil d’analytics tiers identifié dans le code fourni.

## 8. Publicité, tracking et revente des données

SailPilot n’a pas vocation à vendre vos données personnelles.  
À la date du présent document, aucun mécanisme publicitaire tiers ou de tracking publicitaire n’a été identifié dans le build audité.

## 9. Les permissions iOS demandées

Selon l’usage, l’application peut demander :

- **Localisation** : pour la navigation, les cartes, le journal de bord et l’association des événements à la bonne position ;
- **Réseau local** : pour détecter et joindre des passerelles NMEA/AIS sur le réseau du bord ;
- **Photos / bibliothèque** : pour importer des images dans le journal ;
- **Caméra** : pour prendre une preuve photo ;
- **Notifications** : pour les alertes utiles à la navigation ;
- **Face ID / Touch ID** : pour protéger l’accès local à l’application.

Vous pouvez gérer ces autorisations à tout moment dans les réglages iOS.

## 10. Combien de temps les données sont-elles conservées ?

### Données de bord dans l’application
Elles sont conservées **jusqu’à leur suppression par l’utilisateur**, la suppression locale de l’application, ou l’effacement manuel des données.

### Support
Les échanges de support peuvent être conservés pendant une durée raisonnable nécessaire au traitement de la demande et à l’historique du support, puis archivés ou supprimés.

### Données d’achat / abonnement
Les informations de facturation et d’abonnement sont principalement gérées par Apple selon ses propres règles de conservation.

## 11. Où les données sont-elles hébergées ?

Les données principales de journal sont stockées localement sur l’appareil.

Lorsque des services tiers sont sollicités, les données nécessaires à la requête peuvent être traitées sur l’infrastructure de ces fournisseurs, y compris potentiellement hors de l’Espace économique européen selon leurs propres conditions et garanties.

## 12. Sécurité

SailPilot met en œuvre des mesures raisonnables pour protéger les données, notamment :

- stockage local ;
- mécanismes de sécurité du terminal Apple ;
- protection locale par mot de passe / biométrie lorsqu’elle est activée ;
- intégrité locale de certains journaux.

Aucun système n’étant totalement invulnérable, une sécurité absolue ne peut être garantie.
